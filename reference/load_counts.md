# Load Filtered and Raw 10x Genomics Count Matrices

Batch loads 10x Genomics formatted sparse matrices (matrix, features,
and barcodes) for multiple samples. It simultaneously reads both the
'filtered' (cell-containing) and 'raw' (all droplets) outputs from Cell
Ranger using Seurat's `ReadMtx`. Loading both matrices is highly useful
for downstream ambient RNA decontamination workflows (such as SoupX)
that require the empty droplet background to estimate the ambient RNA
profile. Includes a progress bar to track loading status.

## Usage

``` r
load_counts(sample_names, filtered_dir, raw_dir)
```

## Arguments

- sample_names:

  Character vector. A list of sample identifiers corresponding to the
  folder prefixes (e.g., as generated by
  [`get_sample_names()`](https://chomchonu.github.io/OHMmy/reference/get_sample_names.md)).

- filtered_dir:

  Character. The parent directory path containing the
  `"*_filtered_feature_bc_matrix"` folders.

- raw_dir:

  Character. The parent directory path containing the
  `"*_raw_feature_bc_matrix"` folders.

## Value

A named list containing two top-level elements:

- `filtered`: A named list of the filtered sparse count matrices
  (`dgCMatrix`) for each sample.

- `raw`: A named list of the raw sparse count matrices (`dgCMatrix`) for
  each sample.

## Examples

``` r
if (FALSE) { # \dontrun{
# 1. Extract sample names using your helper function
my_samples <- get_sample_names(filtered_dir = "data/filtered_outputs")

# 2. Load both raw and filtered matrices for all samples
counts_list <- load_counts(
  sample_names = my_samples,
  filtered_dir = "data/filtered_outputs",
  raw_dir = "data/raw_outputs"
)

# 3. Access the matrices for the first sample to pass into SoupX
patient1_filt <- counts_list$filtered[["Patient1"]]
patient1_raw  <- counts_list$raw[["Patient1"]]

# Check dimensions
dim(patient1_filt)
dim(patient1_raw)
} # }
```
