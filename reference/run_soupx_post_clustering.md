# Execute Final SoupX Contamination Removal and Seurat Initialization

The second half of the master ambient RNA removal workflow. It takes the
bundled preparation data (generated by `prepare_soupx_inputs`),
estimates the contamination fractions using the high-resolution
clusters, applies any specified manual overrides, and adjusts the count
matrices. Finally, it automatically initializes a fresh list of `Seurat`
objects using the decontaminated counts, returning a comprehensive list
of all objects generated during the process.

## Usage

``` r
run_soupx_post_clustering(
  prep_output,
  multiFac = 0,
  manual_contam = list(),
  pCut = 0.01,
  methods = "subtraction"
)
```

## Arguments

- prep_output:

  A structured list containing `sample_names`, `soup_list`,
  `seurat_for_clustering`, and `counts_lists`. Typically the direct
  output of
  [`prepare_soupx_inputs()`](https://chomchonu.github.io/OHMmy/reference/prepare_soupx_inputs.md).

- multiFac:

  Numeric. A percentage to artificially add to the auto-estimated
  contamination fraction (`rho`). Default is 0.

- manual_contam:

  Character vector. An optional list of specific sample names to
  selectively apply the `multiFac` adjustment to. Default is an empty
  list.

- pCut:

  Numeric. The p-value threshold used for identifying cells expressing
  genes above background levels when `methods = "soupOnly"`. Default is
  0.01.

- methods:

  Character. The method to use for count adjustment passed to
  [`SoupX::adjustCounts()`](https://rdrr.io/pkg/SoupX/man/adjustCounts.html).
  Options include "subtraction", "soupOnly", or "multinomial". Default
  is "subtraction".

## Value

A structured, named list containing three top-level elements:

- `final_seurat`: A list of the final, initialized `Seurat` objects
  containing the background-corrected counts and baseline metadata
  (e.g., `mitoPercent`).

- `soup_objects`: A list of the updated `SoupChannel` objects with their
  calculated `rho` values.

- `seurat_clustering`: A list of the preliminary `Seurat` objects used
  to generate the high-resolution clusters for estimation.

## Examples

``` r
if (FALSE) { # \dontrun{
# 1. Run the preparation phase
soupx_prep_data <- prepare_soupx_inputs(
  filtered_dir = "data/cellranger/filtered",
  raw_dir = "data/cellranger/raw"
)

# 2. Execute the contamination removal and generate final Seurat objects
final_pipeline_output <- run_soupx_post_clustering(
  prep_output = soupx_prep_data,
  multiFac = 2,                 # Add 2% extra contamination penalty
  manual_contam = c("Donor_A"), # Only apply the penalty to Donor_A
  methods = "subtraction"
)

# 3. Extract your final cleaned Seurat objects for downstream integration
my_clean_seurats <- final_pipeline_output$final_seurat
} # }
```
