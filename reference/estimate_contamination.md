# Estimate and Remove Ambient RNA Contamination

Integrates `SoupChannel` objects with initial high-resolution clustering
to automatically estimate the ambient RNA contamination fraction (`rho`)
via
[`SoupX::autoEstCont()`](https://rdrr.io/pkg/SoupX/man/autoEstCont.html).
Includes a robust manual override system allowing you to artificially
increase the estimated contamination fraction (e.g., adding 5% extra
background removal) either globally across all samples or selectively
for specific noisy samples. Finally, it applies the chosen correction
method to remove the background noise and returns the cleaned count
matrices.

## Usage

``` r
estimate_contamination(
  soup_list,
  seurat_list,
  cts_filtered_list,
  sample_names,
  mulFac = 0,
  manual_contam = list(),
  manual = FALSE,
  methods = "subtraction",
  pCut = 0.01
)
```

## Arguments

- soup_list:

  A named list of `SoupChannel` objects, typically generated by
  [`create_soup_channels()`](https://chomchonu.github.io/OHMmy/reference/create_soup_channels.md).

- seurat_list:

  A named list of clustered `Seurat` objects, typically generated by
  [`create_seurat_for_clustering()`](https://chomchonu.github.io/OHMmy/reference/create_seurat_for_clustering.md).
  Used solely to supply high-resolution cluster identities back to the
  SoupChannels.

- cts_filtered_list:

  A named list of filtered sparse count matrices. Used to extract the
  exact cell barcodes to ensure 1:1 mapping with the clusters.

- sample_names:

  Character vector. A list of sample identifiers corresponding to the
  names in the input lists.

- mulFac:

  Numeric. A percentage to artificially add to the auto-estimated
  contamination fraction (e.g., `mulFac = 5` adds `0.05` to the `rho`
  value). Default is 0.

- manual_contam:

  Character vector. A list of specific sample names to apply the
  `mulFac` adjustment to. Only evaluated if `manual = TRUE`. Default is
  an empty list.

- manual:

  Logical. Controls the application of `mulFac`. If `FALSE`, `mulFac` is
  applied globally to ALL samples. If `TRUE`, `mulFac` is applied ONLY
  to the specific samples listed in `manual_contam`. Default is FALSE.

- methods:

  Character. The method to use for count adjustment passed to
  [`SoupX::adjustCounts()`](https://rdrr.io/pkg/SoupX/man/adjustCounts.html).
  Options include "subtraction", "soupOnly", or "multinomial". Default
  is "subtraction".

- pCut:

  Numeric. The p-value threshold used for identifying cells expressing
  genes above background levels when `methods = "soupOnly"`. Default is
  0.01.

## Value

A named list containing two elements:

- `soup_list_all`: A list of the updated `SoupChannel` objects with
  their final `rho` values calculated and set.

- `corrected_list`: A list of the final, decontaminated sparse count
  matrices (rounded to integers), ready to be used to create your final
  Seurat objects.

``` r

# Assuming soup_channels and seurat_clusters were generated previously

# Example 1: Run standard auto-estimation with no manual overrides

  methods = "subtraction"

  soup_list = soup_channels,
  seurat_list = initial_seurat_objs,
```
